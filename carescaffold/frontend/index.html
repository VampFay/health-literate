Compliance Disclosure

  • •Not "HIPAA certified" — no such certification exists. PHI redaction tested against HIPAA Safe Harbor (45 CFR 164.514(b)(2)); 91% recall / 85% precision on 152-case corpus.
  • •Not "ONC certified" — FHIR R4 self-tested; Inferno Docker run not performed (sandbox constraint).
  • •100% synthetic data — all patient data from Synthea. Never touched real PHI.
  • •BAA not required — no real PHI processed. Production would require a BAA.
